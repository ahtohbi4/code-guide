# Проверка комплекта

Дата: 11 октября 2026 года. Проверка изолирована от демо-витрины.

## Результат

- Зависимости установлены с проверкой peerDependencies, без `--force` и `--legacy-peer-deps`.
- Чистая повторная установка по lockfile через `npm ci --offline --ignore-scripts` успешна.
- Корректные TS/TSX-примеры проходят ESLint и TypeScript; CSS-пример проходит Stylelint.
- Девять отрицательных примеров проверяют `===`, запрет `any`, явный публичный возвращаемый тип, число параметров, необработанный promise с `void`, async callback в forEach, порядок обязательных полей, non-null assertion и type кнопки.
- Девять CSS-примеров проверяют запрещённые shorthand, селекторы тегов и ID, `!important`, `transition-property: all`, группы и алфавитный порядок.
- Дополнительный TypeScript-пример подтверждает strict null checking, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- Formatter проверен на шаблоне `if` и корректных примерах. Проверено форматирование файлов комплекта.
- Конфигурации и скрипт проверки проходят собственный ESLint без ошибок и предупреждений.

Команда воспроизведения: `npm ci --ignore-scripts`, затем `npm run verify` внутри этого каталога. Проверено на Node.js 24.20.0. Минимальная версия Node.js отдельно не проверялась; требования runtime сверять с используемыми пакетами.

## Ограничения и сопровождение

ESLint 10.12.0 не прошёл разрешение peerDependencies: eslint-plugin-jsx-a11y 6.10.2 объявляет поддержку до ESLint 9. Поэтому комплект использует совместимый ESLint 9.39.5. npm сообщает, что эта версия больше не поддерживается. Это ограничение проверенного набора: после появления совместимых плагинов обновить ESLint и повторить проверку. Принятие этого комплекта не означает автоматического разрешения обновлять framework или зависимости приложения.

Не проверялись браузерная accessibility, поддержка всех framework и monorepo, реальные приложения на новом стандарте и полное покрытие всех CSS-свойств. Матрица автоматизации в CODE_STYLE.md явно отделяет проверки инструментов от review.

В JSX и объектах сортировка может менять порядок вычисления выражений. CSS sorting может менять каскад. Не включать безусловное массовое исправление; значимый порядок сохраняется с локальным обоснованием.

Исходный package.json, lockfile, AGENTS.md и код демо-витрины не изменялись этой задачей. Применение стандарта к приложению — отдельная работа.
